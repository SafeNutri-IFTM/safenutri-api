# API - SAFENUTRI ![API](https://img.shields.io/badge/API-yellow)

<img src="src/assets/LogoSafeNutri-horizontal.png" width="30%" alt="Logo SafeNutri">

Este é o repositório oficial da API do SafeNutri, um sistema de recomendações de receitas para pessoas com restrições alimentares, uma aplicação desenvolvida para auxiliar os usuários a não precisar mais ficar horas procurando receitas que sejam seguras para ele, pois o sistema já vai filtrar e sugerir receitas fornecidas por profissionais, se baseando na sua restrição alimentar.

## Tecnologias Utilizadas

- [Java](https://www.oracle.com/br/java/technologies/downloads/#java25): Linguagem para desenvolvimento da aplicação backend.
- [Spring Boot](https://spring.io/projects/spring-boot): Framework para construção de APIs e serviços backend.

Pré-requisitos

- JDK 25
- Maven

## Instruções de Instalação

- Clone o repositório:

  - git clone git@github.com:SafeNutri-IFTM/safenutri-api.git

- Execute o servidor de desenvolvimento:

  - mvn spring-boot:run

- Acesse o swagger:

  - Abra o navegador e vá para <http://localhost:8080/swagger-ui/index.html>
